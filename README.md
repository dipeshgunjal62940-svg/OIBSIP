 # OIBSIP — Python Internship Projects

This repository contains Python projects developed as part of my programming internship tasks with Oasis Infobyte.

## Projects

### 1. BMI Calculator

A Python application that calculates Body Mass Index (BMI) using weight and height.

**Features**

* Command-line interface (CLI)
* Graphical interface using Tkinter
* Input validation and BMI categorization
* SQLite database for storing BMI records
* User-specific calculation history
* BMI trend visualization using Matplotlib

**Technologies:** Python, Tkinter, SQLite, Matplotlib

**Project folder:** `BMI-Calculator/`
